# lan-hosts

静态名字映射与分发组件（M4 / PRD §4.6）。默认端口 `8084`，零第三方 crate。

## 1. 定位与边界

`lan-hosts` 是 `name <-> ip` 映射的**单一数据源**：登记 / 校验 / 批量导入 → 渲染标准 hosts 文本 → 按需原子发布到本机文件，并提供只读拉取端点。

### 与 lan-mdns 无重叠、无耦合

| 项 | lan-hosts | lan-mdns |
| --- | --- | --- |
| 职责 | 静态映射的登记、渲染、文件发布 | 组播 DNS 应答与服务发现 |
| 名字空间 | `hosts.*`，默认拒绝 `.local` | mDNS `.local` 名字 |
| 网络 | 只监听自身 HTTP 端口，不发组播、不构造 DNS 报文 | 监听组播、构造 DNS 报文 |
| 数据 | 只写 `lan-hosts.mappings.json` / `lan-hosts.out` | 自有配置、快照、网关路由 |
| 联动 | 无；导出后由人工导入，不调用其 API | 无 |

**明确不做**：组播应答、DNS 服务器、HTTP 正向 / 反向代理、向其他组件推送配置或读取其他组件的配置 / 快照 / API。业务数据不进配置快照（避免导入配置时覆盖映射），由自身 JSON lines 文件承担备份。

## 2. 配置字段（`hosts.*`）

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `hosts.allow_local_suffix` | `false` | 是否允许 `.local` 结尾的 name / alias；默认拒绝以与 mDNS 划清边界 |
| `hosts.conflict_policy` | `reject` | `reject`：同名不同 IP 拒绝（返回 `invalid_config`）；`upsert`：同名覆盖 |
| `hosts.mappings_path` | `lan-hosts.mappings.json` | 业务数据（JSON lines）路径，禁止 `..` |
| `hosts.output_path` | `lan-hosts.out` | 渲染产物发布路径，禁止 `..` |
| `hosts.max_mappings` | `2000` | 映射条数硬上限，校验范围 `1..100000` |
| `hosts.publish_enabled` | `false` | 显式开启才允许写文件；关闭时发布返回错误，不静默成功 |
| `hosts.include_header` | `true` | 渲染时是否加 `# generated by lan-hosts — do not edit` 头 |

`name` / `alias` 约束：小写字母 / 数字 / 连字符 / 点，长度 ≤ 253，不能以点开头或结尾。`ip` 用 `IpAddr::from_str` 校验（IPv4 / IPv6 均可）。

`Mapping` 字段：`name`、`ip`、`aliases[]`、`comment`、`tags[]`、`enabled`、`updated_at`（UTC RFC 3339）。

## 3. 端点

所有响应沿用 `common_api::ok/err` 统一信封；写端点用 `route_write`，复用 `X-Admin-Password` 管理员密码鉴权。

| 方法 | 路径 | 说明 | 返回 `data` |
| --- | --- | --- | --- |
| GET | `/api/hosts/mappings` | 映射清单 | `{"items":[...],"total":N,"conflicts":N}` |
| POST | `/api/hosts/mapping` | UPSERT 单条，body `{"name","ip","aliases"?,"comment"?,"tags"?,"enabled"?}` | `{"name":...,"total":N}` |
| POST | `/api/hosts/remove` | 按 `name` 删除，body `{"name"}` | `{"removed":true\|false}` |
| POST | `/api/hosts/import` | 导入标准 hosts 文本，body `{"text"}` | `{"imported":N,"skipped":N,"conflicts":N}` |
| GET | `/api/hosts/render` | 只读渲染，`?format=hosts\|json` | `{"format":...,"text":...,"bytes":N,"lines":N}`（`text` 已 JSON 转义） |
| POST | `/api/hosts/publish` | 渲染 → 原子发布到 `output_path` | `{"published":true,"bytes":N,"path":...}` |
| GET | `/api/hosts/status` | 映射数 / 计数器 / 上次发布 | `{"mappings":N,"conflicts":N,"published":N,"publish_failed":N,"render_bytes":N,"publish_enabled":bool,"last_publish":...}` |

说明：

- `render` 过滤 `enabled=false`，展开 `name + aliases`，按 `(name, ip)` 排序去重，输出 `ip<TAB>name` 行，稳定可复现。`format=hosts` 返回 hosts 文本，`format=json` 返回映射清单的紧凑 JSON；两者的 `text` 都经 `json_quote` 转义。
- `import` 跳过空行、`#` 注释及行内 `#` 注释；首列为 IP，首个名字作 `name`，其余作 `aliases`；逐条按 `conflict_policy` UPSERT。`skipped` 为校验失败行，`conflicts` 为冲突 / 保留后缀被拒行。
- `publish` 先写 `<output_path>.tmp` 再 `fs::rename` 原子替换；任何失败（含目录不存在、路径非法、未开启）都保留旧文件完好、计数 `publish_failed` 并发 `hosts_publish_failed` 告警，返回 `409 invalid_config`。

## 4. 运维 curl 示例

```bash
BASE=http://127.0.0.1:8084

# 首次设置管理员密码（所有写操作都需要）
curl -s -X POST "$BASE/api/auth/password" \
  -H 'Content-Type: application/json' \
  -d '{"new_password":"change-me-now"}'

PASS='X-Admin-Password: change-me-now'

# 登记一条映射
curl -s -X POST "$BASE/api/hosts/mapping" -H "$PASS" \
  -H 'Content-Type: application/json' \
  -d '{"name":"nas.lan","ip":"192.168.5.10","aliases":["storage.lan"],"comment":"NAS","tags":["storage"],"enabled":true}'

# 批量导入标准 hosts 文本
curl -s -X POST "$BASE/api/hosts/import" -H "$PASS" \
  -H 'Content-Type: application/json' \
  -d '{"text":"# comment\n192.168.5.30 printer.lan alias.lan\n192.168.5.40 cam.lan\n"}'

# 渲染预览（只读，不需要密码）
curl -s "$BASE/api/hosts/render?format=hosts" | python3 -m json.tool

# 查看清单与状态
curl -s "$BASE/api/hosts/mappings" | python3 -m json.tool
curl -s "$BASE/api/hosts/status" | python3 -m json.tool

# 开启发布（先改配置并保存 / reload），再发布
curl -s -X POST "$BASE/api/hosts/publish" -H "$PASS" \
  -H 'Content-Type: application/json' -d '{}'

# 删除
curl -s -X POST "$BASE/api/hosts/remove" -H "$PASS" \
  -H 'Content-Type: application/json' -d '{"name":"cam.lan"}'
```

离线校验配置（不监听端口）：

```bash
lan-hosts --check --config lan-hosts.yaml
```

## 5. 指标

短名由运行时自动加上 `lanstudio_hosts_` 前缀（见 `docs/METRICS.md` §3.6）。

| 指标 | 类型 | 说明 |
| --- | --- | --- |
| `lanstudio_hosts_mappings` | gauge | 已登记映射数 |
| `lanstudio_hosts_conflicts_total` | counter | 同名异 IP / `.local` 保留后缀被拒绝次数 |
| `lanstudio_hosts_published_total` | counter | 成功发布次数 |
| `lanstudio_hosts_publish_failed_total` | counter | 发布失败次数（旧文件保持完好） |
| `lanstudio_hosts_render_bytes` | gauge | 上次渲染字节数 |

## 6. 告警 kind

| kind | level | 触发 |
| --- | --- | --- |
| `hosts_conflict_detected` | warning | 单条 UPSERT / 导入命中 `reject` 冲突或 `.local` 保留后缀 |
| `hosts_publish_failed` | warning | 发布被关闭、路径非法或写文件失败 |

## 7. 不做的部分

- 不监听 5353、不加入组播组、不构造 / 应答 DNS 报文；
- 不实现 HTTP 正向 / 反向代理或 Host 路由转发；
- 不向 `lan-mdns`（或任何组件）推送映射，不读取其配置 / 快照 / API；
- 不实现 ICMP / ARP 探测、远程控制、跨组件联动（留给 M5 统一出口）；
- 不含任何第三方 crate、不使用 serde；JSON 与 hosts 文本均手写解析 / 序列化。
