Lan Studio

lan-mdns · M2.2 可观测 + 安全 + 配置生命周期 · 内嵌离线页面

本页由二进制编译期内嵌，运行时不依赖任何外部静态文件、CDN 或网络。

当前里程碑 M2.2：真实 mDNS / DNS-SD 引擎之上已补齐管理员密码写保护、配置保存 / 快照 / 历史 / 回滚 / 导入导出 / 热重载、有界结构化日志与磁盘轮转、SSE 实时日志流、TCP 健康目标、名称冲突聚合、服务地图 TTL 老化，以及 13 个专有 Prometheus 指标族。

本页仍是占位页。按 PRD 7.5，Arco Design 正式管理台在 M2.4 交付；告警、内置 HTTP 网关与部署运维在 M2.3 上线。

写操作需管理员密码。 首次未设置时所有写路由返回 409 setup_required；先 POST /api/auth/password 设置，再带 X-Admin-Password 请求头。管理接口默认仅监听 127.0.0.1。

基础与协议

  • GET /healthz 存活探针，恒返回 ok
  • GET /readyz 就绪探针
  • GET /api/status 协议状态、引擎计数与运行态状态位
  • GET /api/metrics Prometheus 0.0.4 指标
  • GET /api/records 已发布 RR 集合
  • GET /api/interfaces 本机网卡枚举
  • POST /api/probe 主动探针（name / type / unicast）

可观测

  • GET /api/queries 有界查询审计（支持 CSV 导出）
  • GET /api/browse 外来应答 + 服务类型聚合地图
  • GET /api/conflicts 名称冲突登记
  • GET /api/health/targets 业务健康目标 up / down / unknown
  • GET /api/logs 有界结构化日志与磁盘上界
  • GET /api/logs/stream SSE 实时日志流（replay + keepalive）
  • GET /api/alerts 告警状态占位（M2.3）

配置生命周期（写操作需 X-Admin-Password）

  • GET /api/config 当前配置原文与结构化摘要
  • POST /api/config 保存：校验 → 快照 → 原子替换 → 热重载
  • GET /api/config/snapshot 导出快照；?id= 读取历史快照
  • POST /api/config/snapshot 导入快照（校验 checksum）
  • GET /api/config/history 有界版本历史
  • POST /api/config/rollback 一键回滚
  • POST /api/reload 手动热重载

安全

  • GET /api/auth 鉴权状态
  • POST /api/auth/password 设置 / 修改管理员密码
  • POST /api/auth/verify 校验管理员密码
