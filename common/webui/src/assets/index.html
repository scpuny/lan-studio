lan-mdns · M2.1 协议内核 · 内嵌离线页面

本页由二进制编译期内嵌，运行时不依赖任何外部静态文件、CDN 或网络。

当前里程碑 M2.1：真实 mDNS / DNS-SD 引擎已上线——组播收发、查询应答、启动与周期宣告、退出 Goodbye、QU 单播应答、Known-Answer 抑制、外来应答摄取与主动探针。

本页仍是占位页。按 PRD 7.5，Arco Design 正式管理台在 M2.4 交付；可观测、配置生命周期、告警与网关分别在 M2.2 / M2.3 上线。

已实现的契约端点

  • GET /healthz 存活探针，恒返回 ok
  • GET /readyz 就绪探针
  • GET /api/status 协议状态与引擎统计
  • GET /api/metrics Prometheus 0.0.4 指标
  • GET /api/config 当前配置原文
  • GET /api/auth 鉴权状态
  • GET /api/records 已发布 RR 集合
  • GET /api/interfaces 本机网卡枚举
  • GET /api/queries 有界查询审计
  • GET /api/browse 外来应答摄取
  • POST /api/probe 主动探针（name / type / unicast）
